# Panda Dummy Website

This repository contains the first website I created using HTML and inline CSS. The website showcases interesting facts about pandas and includes a video at the end.

## Features

Displays fascinating facts about pandas.

Includes a picture of a panda.

Ends with a video of a panda to make it engaging.


### Files in the Repository

1. index.html: The main HTML file containing the website's structure and content.


2. panda.jpg: An image of a panda displayed on the website.


3. panda.mp4: A video of a panda embedded at the end of the webpage.



## How to View the Website

1. Clone the repository to your local machine:
```bash
git clone https://github.com/Sawa-Abraham-O/panda_dummy_website.git
```

2. Navigate to the folder:
```bash
cd panda_dummy_website
```

3. Open the index.html file in any web browser to view the website.
